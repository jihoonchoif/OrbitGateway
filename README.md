OrbitGateway is a Cloud-based Smart Platform that leverages Auto-scaling architecture for Real-time Processing and seamless data exchange.

With OrbitGateway, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/OrbitGateway.git`
2. `cd OrbitGateway`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
